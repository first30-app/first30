# 퍼스트30 (First30)

**사고 직후 30초, 무엇을 해야 할지 차가 먼저 알려주는 동반자 앱.**
차로변경 접촉사고가 나면 Pleos Connect 앱이 충돌 전 차량 기록(방향지시등·핸들·브레이크·속도·진행 방향, 최근 20초)을
봉인하고, 안전 행동 → 기록 보존 → 예상 과실 범위(참고치) → 현장에서 할 말 → 다음 단계를 30초 안에 음성으로 안내합니다.

> 예상 과실은 손해보험협회 과실비율 인정기준의 참고치이며, 확정 과실은 보험사·분쟁심의위원회가 정합니다.
> 숫자는 차가 충돌 순간을 직접 감지했고(에어백·충격 감지) 차량 기록이 사고 유형을 뒷받침할 때만 냅니다.
> 굽은 길·차로가 어긋난 곳을 따라간 움직임은 기록상 진로변경과 똑같이 보이고, 곡선이 바뀌는 곳의 진로변경은 차로 유지처럼 보이기도 해서,
> 앱은 **"그때 (오른쪽) 차로로 진로를 바꾸던 중이었나요?"** 하나를 묻고 **기록과 답이 맞을 때만** 계산합니다 —
> 진로변경 같은 움직임 + "예" → 내 차 진로변경, 차로 유지 + "아니요" → 상대 차 진로변경. 진술 문장만으로는 계산하지 않습니다.
> 회피 조향·정체 저속·기록 결측·방향 기록 지연, 음성·버튼으로만 신고해 충돌 시각을 모를 때는 숫자 대신 "판단 보류"와
> 모아야 할 증거 목록을 보여줍니다. 운전자 진술만으로는 어떤 가감 요소도 확정하지 않습니다.

## 구성

| 폴더 | 내용 |
|---|---|
| `engine/` | 판단 엔진 (JavaScript, 외부 의존성 없음) — 측정 → 사실 문장 → 판정 모델(Jev) → 과실 계산 → 안내 카드 → 기록 봉인 |
| `scenarios/` | 10Hz 차량 신호 합성기와 사고 시나리오 12종 |
| `test/` | 엔진 테스트 |
| `demo/` | 브라우저 시연 화면 (단일 HTML) |
| `android/` | Pleos Connect 앱 (Kotlin) — 작업 예정 |
| `apk/` | 제출용 release APK — 작업 예정 |
| `docs/` | 설계 문서(`DESIGN.md`), 공모전 요강 정리(`CONTEST.md`) |

## 실행 방법

필요: Node.js 18 이상 (추가 설치 없음)

```bash
# 엔진 테스트 (시나리오 12종, 곡선 진입·곡선 끝·굽은 길·차로 어긋남·차선 안 흔들림·회피 조향·GPS 잡음·방향 지연·결측·
#              느린 고속도로 진로변경, 음성 신고·트리거 종류·에어백 시각, 운전자 확인 질문, 진술 해석, 안전 문구, 봉인, 시연 화면 빌드)
npm test            # = node --test test/engine.test.js

# 시연 화면 만들기 → demo/index.html 을 브라우저로 열기
npm run build:demo  # = node demo/build.js
```

시연 화면에서 사고 장면을 고르고 **30초 안내 시작**을 누르면 차량 화면과 음성 안내(선택)가 나옵니다.
진술 칸을 고치거나 "그때 (오른쪽) 차로로 진로를 바꾸던 중이었나요?" 질문에 예/아니요로 답하면 판정이 다시 계산됩니다.

### 판정 모델 연결 (선택)

기본값은 오프라인 규칙 판정기(`local-standin`, 화면에 "오프라인 대체 판정기"로 표시)입니다.
TypeSafe Jev로 판정하려면 API 키를 가진 중계 서버를 두고 `engine/jev-client.js` 의 `makeJevJudge({ endpoint })` 로 연결합니다.
차량 앱에는 API 키를 넣지 않습니다. 응답이 3초 안에 오지 않으면 오프라인 판정으로 자동 전환합니다.

## 테스트 환경

- 엔진·시연: Node.js 18+ / 최신 Chrome·Edge·Safari (음성 안내는 브라우저의 한국어 TTS 사용)
- 차량 앱(예정): Pleos Connect SDK 에뮬레이터 `Pleos_Connect_v2.1` (Android 14), Vehicle SDK 2.3.2, JDK 17, AGP 8.8.2, Kotlin 2.0.0, minSdk 28
- 필요한 권한(예정): 방향지시등·핸들·브레이크·에어백·착석 상태 읽기, 위치(FusedLocation), 차량 속도, 마이크(음성 진술)
